🔄 Re-import Business Data

Clears all Firestore data (Finances, Tasks, Team, Capital Projects) and re-imports from admin/data.json. Use this when the source data file has been updated.

This will replace all editable data. Form submissions and analytics are not affected.

📊 Platform Info

  • Database: Firebase Firestore (Spark plan — free)
  • Hosting: Netlify (free tier)
  • Analytics: Custom Firestore tracker + Netlify baseline
  • Merch: Printful (on-demand, no upfront cost)
  • Auth: Firebase Authentication
